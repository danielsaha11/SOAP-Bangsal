Pengaturan Sinkronisasi Cloud (Firebase)

Cara Menghubungkan HP Android, Tablet, dan Laptop Windows:

  1. Buat proyek gratis di Firebase Console dan aktifkan Firestore Database serta Anonymous Authentication.
  2. Salin objek konfigurasi firebaseConfig dalam format JSON dan tempelkan di kolom bawah.
  3. Masukkan Kode Ruang Sinkronisasi yang sama pada seluruh perangkat Anda.

Gunakan kode unik pribadi agar data pasien Anda terpisah dari pengguna lain.

Jika dikosongkan, aplikasi tetap berjalan lancar dalam Mode Lokal menggunakan penyimpanan peramban perangkat Anda.
